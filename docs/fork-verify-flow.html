路径 A：GitHub Release 一键 npm install，团队可用
路径 B：cp 替换 最快验证，无需 Release
1 在 GitHub 上 Fork 仓库 必须

浏览器打开 https://github.com/chenhg5/cc-connect，点击右上角 Fork 按钮。Fork 完成后你的仓库地址为：

bash — 添加 fork remote（仅首次）
$ git remote add fork git@github.com:game1991/cc-connect.git # 确认 remote $ git remote -v origin https://github.com/chenhg5/cc-connect.git (上游) fork git@github.com:game1991/cc-connect.git (你的 fork)
✓ 命名约定：origin 保留为上游，fork 指向你的仓库。这样既能 push fork，又能 git pull origin main 同步上游变更。
2 修改 Fork 版本号 关键

将 Makefile 中的 VERSION 改为 fork 专用版本号，避免与上游 npm 包版本冲突。

Makefile
# 修改前（上游版本） VERSION := v1.3.3-beta.4 # 修改后（fork 版本） VERSION := v1.3.3-fork.1
⚠ 版本号规则：使用 vX.Y.Z-fork.N 格式。run.js 会比较 bin/cc-connect.exe 的输出与 package.json 中的版本号。如果 fork 版本号 ≥ 官方版本号，就不会触发自动重装覆盖你的二进制。
3 编译 Release 包 必须
bash
# 编译 Windows amd64 包（跳过 Web 前端） $ make release-noweb TARGET=windows/amd64 Built: dist/cc-connect-v1.3.3-fork.1-windows-amd64.exe # 打包 zip $ cd dist $ zip cc-connect-v1.3.3-fork.1-windows-amd64.zip \ cc-connect-v1.3.3-fork.1-windows-amd64.exe $ sha256sum cc-connect-v1.3.3-fork.1-windows-amd64.zip > checksums.txt
✓ 产物确认：dist/cc-connect-v1.3.3-fork.1-windows-amd64.zip 已生成
4 提交、打 Tag 并 Push 到 Fork 必须
bash
# 提交所有修改 $ git add -A $ git commit -m "feat: fork version v1.3.3-fork.1" # 打 tag（与 VERSION 一致） $ git tag v1.3.3-fork.1 # Push 到 fork 仓库（非 origin 上游） $ git push fork feat/role-based-tool-permissions $ git push fork v1.3.3-fork.1
5 在 Fork 仓库创建 GitHub Release 必须

Release 是 npm install 的下载源——install.js 会拼出 URL 并从中下载 zip。以下是完整的浏览器操作步骤：

操作步骤： 1. 打开 Release 创建页面 浏览器访问： https://github.com/game1991/cc-connect/releases/new （或从仓库首页 → Releases → Draft a new release） 2. 填写 Release 信息 Choose a tag: v1.3.3-fork.1 （选择刚 push 的 tag） Release title: cc-connect v1.3.3-fork.1 Describe this release: （参考下方模板） 3. 上传产物 拖入或选择文件： dist/cc-connect-v1.3.3-fork.1-windows-amd64.zip dist/checksums.txt 4. 点击 "Publish release"
Release Description 模板（直接复制）
## cc-connect v1.3.3-fork.1 Fork of cc-connect v1.3.3-beta.4 ### Bug 修复 - **daemon install** 配置 fallback：三级查找（--config → WorkDir/config.toml → ~/.cc-connect/config.toml） - **launcher --config 传递**：PowerShell / systemd / launchd 启动命令均传递 --config 参数 ### 新功能 - **角色级权限模式**：per-role mode + allowed_tools（yolo / default / dontAsk） - **权限审批身份校验**：仅发起者或 admin 可批准工具请求 - **Bridge 卡片身份修复**：传递真实 userID，默认身份改为 bridge-user ### 安装 npm install -g github:game1991/cc-connect#feat/role-based-tool-permissions ### 校验 sha256sum -c checksums.txt
⚠ 关键：Release 中的 zip 文件名必须匹配 install.js 的拼装规则 {name}-{version}-{platform}-{arch}{ext}。如果 VERSION 是 v1.3.3-fork.1，则 zip 中 exe 名称必须为 cc-connect-v1.3.3-fork.1-windows-amd64.exe。make release-noweb 已自动按此格式命名。
✓ 下载 URL 确认：发布后 npm install 将从以下地址下载二进制：
https://github.com/game1991/cc-connect/releases/download/v1.3.3-fork.1/cc-connect-v1.3.3-fork.1-windows-amd64.zip
6 修改 package.json + install.js 指向 Fork 关键

npm 包的 install.js 硬编码了上游仓库地址，需改为你的 fork。同时 package.json 版本号需与 fork VERSION 一致。这两个文件不在 Go 源码仓库中，需要从官方 npm 包复制后修改，或者将它们加入 fork 仓库。

package.json — 改 3 处
{ "version": "1.3.3-fork.1", "homepage": "https://github.com/game1991/cc-connect", "repository": { "type": "git", "url": "https://github.com/game1991/cc-connect.git" } }
install.js — 改 2 处
// 上游原值： const GITHUB_REPO = "chenhg5/cc-connect"; const GITEE_REPO = "cg33/cc-connect"; // 改为 fork： const GITHUB_REPO = "game1991/cc-connect"; const GITEE_REPO = "game1991/cc-connect"; // 或保留 Gitee 上游
⚠ 文件来源：package.json 和 install.js 不在 Go 源码仓库中。它们随 npm install -g cc-connect@beta 安装到 $(npm root -g)/cc-connect/。首次安装官方包后直接修改该目录下的这两个文件即可。
7 通过 npm 安装 Fork 版本 必须
bash — 从 GitHub 仓库直接安装
# 从 fork 仓库安装指定分支 $ npm install -g github:game1991/cc-connect#feat/role-based-tool-permissions # 安装后 postinstall 自动从 GitHub Release 下载二进制 [cc-connect] Downloading from https://github.com/game1991/cc-connect/releases/download/v1.3.3-fork.1/... [cc-connect] Installed to D:\nodejs\node_global\node_modules\cc-connect\bin\cc-connect.exe
✓ 一键安装：以后团队成员只需一行 npm install 即可安装 fork 版本
8 卸载旧 Daemon → 重装 必须
bash
# 停止旧 daemon $ cc-connect daemon stop # 卸载 schtasks 计划任务 $ cc-connect daemon uninstall # 确认无残留进程 $ ps -W | grep -i cc-connect | grep -v grep # 重装 daemon（fork 修复后无需 --config） $ cc-connect daemon install cc-connect daemon installed and started. Platform: schtasks Binary: ...cc-connect.exe
9 验证 关键
bash
$ cc-connect --version cc-connect v1.3.3-fork.1 commit: a4558147 $ cc-connect daemon status Status: Running
↻ 维护：发布新版本（后续迭代） 持续

当 fork 有新修改需要发布时，只需重复以下流程：

bash — 发布新版本完整流程
# ═══ 1. 修改版本号 ═══ # 编辑 Makefile，将 VERSION 递增 VERSION := v1.3.3-fork.2 # fork.1 → fork.2 → fork.3 ... # 同步修改 $(npm root -g)/cc-connect/package.json $ sed -i 's/"1.3.3-fork.1"/"1.3.3-fork.2"/' \ "$(npm root -g)/cc-connect/package.json" # ═══ 2. 编译 + 打包 ═══ $ make release-noweb TARGET=windows/amd64 $ cd dist && \ zip cc-connect-v1.3.3-fork.2-windows-amd64.zip \ cc-connect-v1.3.3-fork.2-windows-amd64.exe && \ sha256sum *.zip > checksums.txt # ═══ 3. 提交 + 打 Tag + Push ═══ $ git add -A && \ git commit -m "chore: bump version to v1.3.3-fork.2" $ git tag v1.3.3-fork.2 $ git push fork feat/role-based-tool-permissions $ git push fork v1.3.3-fork.2 # ═══ 4. 创建 GitHub Release ═══ # 浏览器打开 https://github.com/game1991/cc-connect/releases/new # Tag: v1.3.3-fork.2 # Title: cc-connect v1.3.3-fork.2 # 上传: .zip + checksums.txt # Description: 列出本次变更 # ═══ 5. 团队成员更新 ═══ $ npm install -g github:game1991/cc-connect#feat/role-based-tool-permissions # postinstall 自动下载 v1.3.3-fork.2 的二进制 # ═══ 6. 重装 daemon ═══ $ cc-connect daemon stop && cc-connect daemon uninstall $ cc-connect daemon install
✓ 版本号递增规则：小修改 fork.N+1，合并上游新版本 vX.Y.Z-fork.1（重置 N）。始终保持 fork 版本号 ≥ 上游最新版本号，防止 run.js 触发自动重装。

常见问题排查

cp: Device or resource busy
cc-connect.exe 进程仍在运行并锁定了文件。执行 ps -W | grep cc-connect 找到 PID，在管理员终端执行 taskkill /PID <PID> /F。
daemon install 报 "config.toml not found"
当前二进制仍是上游旧版。确认 cc-connect --version 显示 fork commit 后重新安装。路径 A 用户确认 package.json 版本号已改为 1.3.3-fork.1。
npm update 后版本回退
路径 B：npm install -g cc-connect@beta 会覆盖 fork 二进制，需重新 cp。路径 A 不受影响，因为 package.json 版本号已改。
taskkill 提示 Permission denied
需在管理员终端（右键 → 以管理员身份运行）执行。
GitHub Release 下载失败
检查 install.js 中的 GITHUB_REPO 是否指向你的 fork。检查 Release 中 zip 文件名是否匹配 {name}-{version}-{os}-{arch}.zip。中国大陆用户可配 GITEE_REPO 备用源。
