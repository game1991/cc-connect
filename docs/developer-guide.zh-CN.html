版本管理 CRITICAL
版本号格式
v<major>.<minor>.<patch>-fork.<N>

两处存储须同步：

Makefile
VERSION := v1.3.3
npm/package.json
"version": "1.3.3"

同步校验：grep '^VERSION' Makefile 与 node -e "console.log(require('./npm/package.json').version)"

fork.N 排序陷阱 TRAP

run.js 在每次执行时调用 isNewerOrEqual() 判断本地二进制是否需要更新：

1
解析版本号：parseVersion("1.3.3-fork.4") → {nums:[1,3,3], preTag:"fork", preNum:4}
2
比较 major.minor.patch 数字 → 大者胜出
3
数字相同 → 比较预发布标签：无预发布 > 有预发布
4
都有预发布 → preTag 按字典序比较，然后比较 preNum
正确：fork > beta
本地 v1.3.3-fork.4 vs 上游 v1.3.3-beta.5
字典序："fork" > "beta" (f > b)
→ isNewerOrEqual 返回 true → 不重新下载 ✓
陷阱：alpha < beta
本地 v1.3.3-alpha.4 vs 上游 v1.3.3-beta.5
字典序："alpha" < "beta" (a < b)
→ isNewerOrEqual 返回 false → 自动下载覆盖 ✗
违反后果：run.js 自动下载上游版本覆盖本地二进制，导致 fork 功能丢失。必须确保 preTag 字典序始终大于上游可能使用的标签。fork 满足此条件（f > b）。
版本修改检查清单
编辑 Makefile 中的 VERSION
编辑 npm/package.json 中的 version
两处版本号一致
preTag 必须使用 fork，不可改为 alpha/beta/rc
提交信息：chore: bump version to vX.Y.Z-fork.N
打 tag：git tag vX.Y.Z-fork.N

7
平台特定开发笔记
Windows
无 pty
iFlow 使用 creack/pty，Windows 不支持，跳过 pty 测试
schtasks
使用任务计划程序而非 systemd
.old 备份
自更新时当前二进制重命名为 .old
无 syscall.Exec
不支持进程替换，使用 execFileSync 代理
.cmd 弹框
ensureCmdFileAssociation 创建空 OpenWithList 键导致弹框，已移除
macOS
quarantine
下载的二进制可能被 Gatekeeper 隔离，需 xattr -cr cc-connect
launchd
daemon 使用 ~/Library/LaunchAgents/com.game1991.cc-connect.plist
Linux
systemd
daemon 使用 ~/.config/systemd/user/cc-connect.service
run_as_user
通过 sudo 以指定用户身份运行 Agent，含审计日志和预检探针
Unix socket
API Server 使用 ~/.cc-connect/run/api.sock

代码风格与提交规范
Go 风格规则
# 工具检查
gofmt -w .
go vet ./...
golangci-lint run ./...
  • 使用 strings.EqualFold 进行大小写不敏感比较
  • init() 仅用于插件注册
  • 函数超过 ~80 行时提取辅助函数
  • 命名：New() 构造、Get/Set 访问、避免 feishu.FeishuPlatform
错误处理
// 正确：包装错误上下文
return fmt.Errorf("feishu: reply card: %w", err)

// 错误：静默吞掉
if err != nil {
    // 什么也不做 ← 禁止
}

// 日志遮蔽：使用 slog + RedactToken
slog.Error("send failed", "token", core.RedactToken(token))
并发安全
  • Agent session 用 sync.Mutex 或 atomic 保护共享状态
  • 使用 context.Context 传播取消
  • Channel 须明确所有权
  • 一次性清理用 sync.Once（如 pendingPermission.resolve()）
i18n
// 1. 定义消息键
const MsgKeyPermissionDenied = "permission.denied"

// 2. 添加翻译
// core/i18n.go — EN, ZH, ZH-TW, JA, ES

// 3. 使用
e.i18n.T(MsgKeyPermissionDenied)
e.i18n.Tf(MsgKeyPermissionDenied, "tool", toolName)
